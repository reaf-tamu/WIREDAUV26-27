## 1. Overview
An AHRS (Attitude and Heading Reference System) — an IMU (accelerometer + gyro) plus
a magnetometer, fused internally into an orientation estimate.

## 2. What it does and why we use it
- **Sensing principle:** fuses accelerometer, gyroscope, and magnetometer readings internally to estimate orientation.
- **Raw output:** orientation (quaternion/Euler), angular velocity, linear acceleration, compass heading.
- **ROS2 message type:** `sensor_msgs/Imu`
- **Where it goes:** subscribed to by `auv_localization`'s EKF node.
- **What breaks without it:** no attitude/heading reference — attitude PID loops and the state estimator lose their primary orientation input.

## 4. Software setup
### Prerequisites
ROS2 Humble installed (see `docs/jetson-setup.md`).
### Where the code lives
External package, cloned via `dependencies.repos`, not part of this repo's own packages.
### Install / build
```bash
cd ~/auv_ws/src
git clone -b ros2 https://github.com/dawonn/vectornav.git
cd ~/auv_ws && rosdep install --from-paths src --ignore-src -r -y
colcon build --packages-select vectornav
```

## 5. Running it
```bash
ros2 launch vectornav vectornav.launch.py
```
### Verify it's working
```bash
ros2 topic echo /vectornav/imu
```
Expected: orientation/angular velocity values that visibly change when the sensor is tilted by hand.
